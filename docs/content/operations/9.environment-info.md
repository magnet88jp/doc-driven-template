# Environment Info

環境情報は、秘密情報を含めずに、開発と運用に必要な参照情報を整理します。

## 管理する情報

- 利用する Node.js と package manager。
- アプリごとの起動コマンド。
- 必要な環境変数名。
- 外部サービスの参照名。
- デプロイ先や実行環境の種類。

## AWS SAM

AWS SAM のテンプレートは `infra/aws/sam/template.yaml` に置きます。

ToDo DynamoDB provisioning では、SAM stack の output として次の参照名を使います。

| Name | Purpose |
| --- | --- |
| `TodoTableName` | ToDo 永続化に使う DynamoDB table name。 |
| `TodoTableArn` | ToDo DynamoDB table の ARN。権限設定や後続連携で参照する。 |

Web ToDo DynamoDB integration では、`apps/web` が次の環境変数名を参照します。値は repository に書きません。

| Name | Purpose |
| --- | --- |
| `NUXT_TODO_TABLE_NAME` | Nuxt runtime config の `todoTableName`。SAM output の `TodoTableName` を設定する。 |
| `NUXT_AWS_REGION` | Nuxt runtime config の `awsRegion`。DynamoDB table の region を設定する。 |
| `TODO_TABLE_NAME` | Server runtime fallback。`NUXT_TODO_TABLE_NAME` を使えない環境で参照する。 |
| `AWS_REGION` | AWS SDK が参照する region。 |
| `AWS_DEFAULT_REGION` | AWS SDK region fallback。 |

デプロイ時の AWS credentials、profile、secret、token は docs に書きません。

## 書かない情報

- API key、token、password。
- 個人環境だけのパス。
- 一時的な障害回避策。
- 公開すべきでない接続情報。

## AI Agent へのルール

環境変数や外部サービスを追加する場合は、値ではなく名前と用途を docs に記録します。秘密情報を Markdown に書きません。
