# Operations Overview

`operations` は、実際に繰り返し使う標準手順を置く場所です。開発中のタスク進捗や一時的な回避策は delivery に置きます。

## 対象

- Getting Started: AI Agent と人間が共通理解を作るための最初の会話手順。
- 初期設定。
- 日次、週次、月次の確認。
- アドホック対応。
- 環境情報。
- ドキュメント更新手順。

## 運用原則

手順は、担当者が変わっても同じ結果になる粒度で書きます。コマンド、確認対象、完了条件を明示します。環境依存の値は、秘密情報を含めず参照先や設定名で表します。

## AI Agent へのルール

標準手順を変更する実装を行った場合は、operations を更新します。特定タスクだけの暫定作業は operations に書かず、delivery の notes や task に残します。

作りたいものを AI Agent と整理する場合は Getting Started を使います。`apps` 配下のプログラムを起動できる状態にする場合は Initial Setup を使います。
