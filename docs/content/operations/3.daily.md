# Daily Operations

日次運用では、作業前後にリポジトリの状態と docs の整合性を確認します。

## 作業前

- 作業ツリーの差分を確認する。
- delivery の Current Scope を読む。
- 対象 Task と Implementation Flow を読む。
- 対象領域の既存コードと既存 docs を確認する。

## 作業中

- スコープ外の変更を見つけた場合は、実装を広げる前に delivery を確認する。
- 仕様判断が必要な場合は、design の責務境界と原則を確認する。
- 標準手順に影響する場合は、operations 更新対象として記録する。

## 作業後

- 受け入れ条件を満たしているか確認する。
- 可能な範囲で lint、typecheck、test、build を実行する。
- 変更内容に応じて docs を更新する。
