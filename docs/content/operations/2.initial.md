# Initial Setup

初期設定は、開発者または AI Agent が作業前にローカル環境を確認するための標準手順です。

## 前提確認

- Node.js と package manager のバージョンを確認する。
- `apps/web` と `docs` の依存関係をインストールする。
- `.env.example` を確認し、必要な環境変数をローカルに設定する。
- docs サイトが起動できることを確認する。
- Web アプリが起動できることを確認する。

## 標準確認

作業前に、対象アプリの `package.json` を確認します。利用可能な lint、typecheck、test、dev コマンドを把握してから実装します。

## 完了条件

docs と対象アプリがローカルで起動でき、実装対象の検証コマンドが把握できている状態を初期設定完了とします。
