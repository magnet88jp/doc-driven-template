# Initial Setup

Initial Setup は、`apps` 配下のプログラムをローカルで動かすための標準手順です。

docs 配下に設計思想を作成する手順は Getting Started に置きます。このページでは、実装対象アプリの依存関係、環境変数、起動、検証コマンドを扱います。

## 前提確認

- Node.js と package manager のバージョンを確認する。
- 対象アプリの `package.json` を確認する。
- 対象アプリの依存関係をインストールする。
- 対象アプリの `.env.example` を確認し、必要な環境変数をローカルに設定する。
- 対象アプリが起動できることを確認する。

## 標準確認

作業前に、対象アプリで利用可能な lint、typecheck、test、build、dev コマンドを把握してから実装します。

## apps/web

`apps/web` が存在する場合は、次の順で確認します。

1. `apps/web/package.json` を読む。
2. package manager と lockfile を確認する。
3. `.env.example` があれば必要な環境変数名を確認する。
4. 依存関係をインストールする。
5. dev server を起動できることを確認する。
6. 利用可能な検証コマンドを確認する。

## apps/batch

`apps/batch` が存在する場合は、実行環境、依存関係、環境変数、ローカル実行方法、定期実行の確認方法を確認します。

`apps/batch` がまだ存在しない場合は、実装を追加する前に delivery の対象タスクと design の responsibility boundary を確認します。

## 完了条件

対象アプリがローカルで起動でき、実装対象の検証コマンドが把握できている状態を初期設定完了とします。
