# Current Scope

現在のスコープは、Document Driven Monorepo の MVP baseline を整備することです。

## In Scope

- `docs/content` を design、operations、delivery の構成へ再編する。
- AI Agent が実装前に読む入口を delivery に用意する。
- MVP scope と汎用的な実装タスクを定義する。
- 各タスクに Goal、Scope、Out of Scope、Primary Area、Acceptance Criteria、Verification を含める。
- Nuxt Content として読める frontmatter 付き Markdown 構造を保つ。
- Loop Engineering を L1 だけでなく L2/L3 へ発展できる一連のパイプラインとして定義する。
- `maintenance` を状態管理、検証証跡、PR ライフサイクルの保守領域として追加する。

## Design Gap

理想設計では、`apps/web`、`apps/batch`、`packages/shared`、`infra` が責務分離された monorepo として運用されます。

現在は `apps/web` と `docs` が存在し、`apps/batch`、`packages/shared`、`infra` は将来追加する想定です。MVP では、これらを先に実装せず、追加時の判断基準を docs に定義します。

## Out of Scope

- 特定ドメインに依存した業務仕様の確定。
- `apps/batch`、`packages/shared`、`infra` の実装追加。
- Web アプリの大規模な UI 改修。
- 本番デプロイ構成の確定。
- L3 の完全自律運用と自動 merge。

## Active Scope

Active scope: `docs/content/delivery/scopes/1.mvp/1.overview.md`

AI Agent は、実装前にこの Current Scope、対象 Task、Implementation Flow を必ず読みます。

Loop Engineering 関連の作業では、`docs/content/delivery/scopes/1.mvp/tasks/04.mvp-04-loop-engineering-pipeline.md` と `docs/content/design/4.loop-engineering/` も必ず読みます。
