# MVP Overview

MVP scope は、Document Driven Monorepo として開発を始めるための docs baseline を作る段階です。

## Goal

AI Agent と人間が、実装前に同じ Current Scope、Task、Implementation Flow を読める状態を作ります。

## Deliverables

- design docs。
- operations docs。
- delivery docs。
- MVP task list。
- MVP acceptance criteria。
- 汎用的な実装タスク。

## Out of Scope

この scope では、特定ドメインの詳細仕様や本番運用基盤は確定しません。`apps/batch`、`packages/shared`、`infra` は将来追加できる前提を docs に残すだけです。

## Completion Rule

MVP は、docs が Nuxt Content として読め、AI Agent が次のタスクを docs から判断できる状態になったら完了です。
