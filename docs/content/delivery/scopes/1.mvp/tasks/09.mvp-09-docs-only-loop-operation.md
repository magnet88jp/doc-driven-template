# MVP-09 Docs-only Loop Operation

## Goal

Loop Engineering の現状のおすすめ運用を `operations` docs に追記し、docs 作成、L1 candidate 確認、必要に応じたコミット、L2 / L3 gate への進行手順を明確にします。

このタスクは docs の修正だけで Loop Engineering の人間レビュー手順を説明できる状態にすることを目的とします。

## Scope

- `docs/content/operations/3.documentation.md` に Loop Engineering の推奨運用を追記する。
- `pnpm loop:l1` で `STATE.md` に candidate を出す流れを明記する。
- docs と `STATE.md` を人間が確認する手順を明記する。
- 必要なら L2 / L3 gate 前にコミットしてよいことを明記する。
- candidate ID を指定して L2 / L3 gate に進むことを明記する。
- MVP task list に MVP-09 を追加する。

## Out of Scope

- application code の変更。
- Loop Harness の変更。
- `STATE.md` の手動更新。
- L1 / L2 / L3 の自動実行。
- PR 自動作成。
- deploy、credentials、secret、token、`.env`、`.env.*` の変更。

## Primary Area

- `docs/content/operations/3.documentation.md`
- `docs/content/delivery/scopes/1.mvp/2.task-list.md`

## Related Docs

- `docs/content/delivery/2.current-scope.md`

- `docs/content/maintenance/1.state-management.md`

## Acceptance Criteria

- `docs/content/operations/3.documentation.md` に推奨運用が追記されている。
- 推奨運用に docs 作成、`pnpm loop:l1`、docs + `STATE.md` 確認、任意コミット、candidate ID 指定の L2 / L3 gate が含まれている。
- MVP task list に MVP-09 が追加されている。
- code、Harness、infra、secret、credential、`.env` は変更されていない。

## Verification

Maker checks:

```bash
git diff -- docs/content/operations/3.documentation.md docs/content/delivery/scopes/1.mvp/2.task-list.md docs/content/delivery/scopes/1.mvp/tasks/09.mvp-09-docs-only-loop-operation.md
```

Verifier checks:

- 変更が docs 配下に限定されている。
- 推奨運用の手順が operations docs に含まれている。
- MVP-09 の Scope と Out of Scope が docs-only として明確である。

## Notes

このタスクでは `STATE.md` を直接編集しません。L1 candidate は、人間が `pnpm loop:l1` を実行したときに Harness が生成します。
