# Task Title

MVP-04 Docs Section Navigation

## Goal

docs サイトのヘッダーから `design`、`operations`、`delivery` の主要セクションへ移動できる状態を作る。

## Scope

- `docs/app/components/DocsSectionNav.vue` を追加する。
- `AppHeader.vue` に `DocsSectionNav` を組み込む。
- Design、Operations、Delivery の3項目を表示する。
- 現在の path が `/design`、`/operations`、`/delivery` で始まる場合に active state を表示する。
- モバイル表示でヘッダーまたはメニューのレイアウトが崩れないようにする。

## Out of Scope

- docs 全体のナビゲーション設計刷新。
- サイドバー構造の変更。
- 検索 UI、ロゴ、フッターの変更。
- design、operations、delivery の本文再設計。

## Primary Area

`docs/app/components`

## Acceptance Criteria

- ヘッダーに Design、Operations、Delivery が表示される。
- Design は `/design/overview/vision` へ遷移する。
- Operations は `/operations/overview` へ遷移する。
- Delivery は `/delivery/development-roadmap` へ遷移する。
- `/design/*`、`/operations/*`、`/delivery/*` で active state が切り替わる。
- モバイル幅でも主要セクションへの導線が利用できる。

## Verification

- `pnpm --dir docs dev` で docs サイトを起動する。
- ブラウザでヘッダー表示、リンク遷移、active state を確認する。
- モバイル幅で表示崩れがないことを確認する。
- 可能な範囲で `pnpm --dir docs lint` と `pnpm --dir docs build` を実行する。

## Docs Update

このタスクを delivery の MVP task list に追加する。ナビゲーション方針が恒久化される場合は design または operations の更新を検討する。

## Notes

ヘッダー内の実用的なナビゲーションとして扱い、大きな説明文は追加しない。
