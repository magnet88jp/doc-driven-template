# Task Title

MVP-01 Monorepo Docs Baseline

## Goal

`docs/content` を Document Driven Monorepo の開発運用に適した構成へ再編し、AI Agent と人間が同じ docs を読んで実装判断できる状態を作る。

## Scope

- design、operations、delivery の Markdown 構成を作成する。
- 各 Markdown に Nuxt Content 用 frontmatter を付ける。
- Current Scope、Task、Implementation Flow を実装前の入口として定義する。
- MVP scope の概要、タスク一覧、受け入れ条件を作成する。
- テンプレート由来の不要な docs を置き換える。

## Out of Scope

- `apps/web` の UI 改修。
- `apps/batch`、`packages/shared`、`infra` の実装追加。
- 特定ドメインの業務仕様策定。

## Primary Area

`docs/content`

## Acceptance Criteria

- 指定された docs/content 構成が存在する。
- design、operations、delivery の責務が明確に分離されている。
- Implementation Flow に AI Agent への標準指示テンプレートが含まれている。
- 各タスクが指定された見出しを持つ。
- Nuxt Content として読み込める Markdown 構造になっている。

## Verification

- `docs/content` のファイル一覧を確認する。
- docs アプリで build または lint を実行する。
- frontmatter の YAML 構造に明らかな破損がないことを確認する。

## Docs Update

このタスク自体が docs baseline を作成する。実装後、必要に応じて Current Scope と task list の状態を更新する。

## Notes

本文は日本語で簡潔に書く。design には現在進捗を書かず、delivery に現在スコープと差分を書く。
