# Task Title

MVP-02 Web App Baseline

## Goal

`apps/web` を、docs に定義された Web App の責務に沿って確認し、最小限の baseline を整える。

## Scope

- `apps/web` の現在構成を確認する。
- ページ、コンポーネント、server API、型の配置が design の責務境界と矛盾していないか確認する。
- 必要な最小変更を行う。
- 起動、lint、typecheck、build など利用可能な検証を実行する。

## Out of Scope

- 大規模な UI リデザイン。
- 特定ドメインの詳細仕様追加。
- `packages/shared` への本格移行。
- 本番デプロイ設定の追加。

## Primary Area

`apps/web`

## Acceptance Criteria

- `apps/web` の構成が design の Web App 責務と大きく矛盾していない。
- 実装変更がある場合、対象ページまたは API の挙動が確認できる。
- 共有すべき契約が見つかった場合、delivery に shared contract baseline の対象として記録されている。
- docs と実装の説明が矛盾していない。

## Verification

- `apps/web/package.json` の利用可能な検証コマンドを確認する。
- 実行可能な lint、typecheck、build、test を実行する。
- UI 変更がある場合はブラウザで主要画面を確認する。

## Docs Update

Web App の責務や標準手順が変わった場合は、design または operations を更新する。現在スコープや次タスクに影響する場合は delivery を更新する。

## Notes

このタスクは汎用 baseline 用であり、特定ドメインの機能追加を目的にしない。
