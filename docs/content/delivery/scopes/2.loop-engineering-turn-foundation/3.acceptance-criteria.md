# Loop Engineering Turn Foundation Acceptance Criteria

この scope は、次の条件を満たしたときに受け入れ可能です。

## Criteria

- task Markdown の共通 schema が docs に定義されている。
- 開始時点の task が schema に従っている。
- task status、autonomy、verification commands、handoff conditions の扱いが明確である。
- `STATE.md`、`.loop/state.json`、`.loop/runs/*.md` の責務分離が docs と Harness に反映されている。
- `STATE.md` は最新状況を人間が読むための dashboard として扱われる。
- Harness が task ID から brief を生成できる。
- brief に source docs、related docs、scope、out of scope、Maker checklist、Verifier checklist、handoff triggers が含まれる。
- brief 生成は secret、credential、token、`.env`、`.env.*` の値を読まない。
- Verifier が `node --check scripts/loop-harness.mjs` と関連 command evidence を残せる。
- 将来 scope の詳細 task が先に作られていない。

## Verification

この scope の verifier は、少なくとも次を確認します。

```bash
node --check scripts/loop-harness.mjs
pnpm --dir docs typecheck
```

LE-03 完了後は、代表 task ID に対して brief 生成も確認します。

```bash
pnpm loop:brief <task-id>
```

実行できない command がある場合は、未実施理由と blocker を verifier evidence に残します。
