# LE-03 Harness Brief Generation

## Goal

Harness が task ID から source docs、related docs、scope、out of scope、Maker checklist、Verifier checklist、handoff triggers を集め、実装前に人間と Agent が同じ brief を確認できる状態にする。

## Scope

- `pnpm loop:brief <task-id>` または同等の command を追加する。
- Harness が task ID に対応する task Markdown を解決できるようにする。
- task Markdown の Related Docs、Acceptance Criteria、Verification、Out of Scope を brief に含める。
- Maker checklist を生成する。
- Verifier checklist を生成する。
- handoff triggers と denylist reminder を生成する。
- brief は標準出力または repository 内の安全な一時 Markdown として確認できるようにする。
- secret、credential、token、`.env`、`.env.*` の値を読まない。

## Out of Scope

- PR の自動作成。
- GitHub API 呼び出し。
- 自動 commit。
- 自動 merge。
- 実装コードの自動生成。
- Active Loop Dashboard の UI 実装。

## Acceptance Criteria

- task ID を指定して brief を生成できる。
- unknown task ID では明確な error を返す。
- brief に source docs と related docs が含まれる。
- brief に scope と out of scope が含まれる。
- brief に Maker checklist が含まれる。
- brief に Verifier checklist が含まれる。
- brief に handoff triggers と denylist reminder が含まれる。
- brief 生成は secret、credential、token、`.env`、`.env.*` の値を読まない。
- command が package scripts または operations docs に反映されている。

## Verification

```bash
node --check scripts/loop-harness.mjs
pnpm loop:brief LE-01
pnpm --dir docs typecheck
```

Verifier は、生成された brief に task ID、source docs、Maker checklist、Verifier checklist、handoff triggers が含まれることを確認します。
