# Web App

`apps/web` は、ユーザーが直接利用する Nuxt アプリケーションです。UI、画面遷移、フォーム、表示状態、Web 固有のサーバー API を担当します。

## 責務

- ページとレイアウトを提供する。
- ユーザー操作に応じた表示状態を管理する。
- Server API を通じてデータを取得、更新する。
- Web 固有のエラー表示、空状態、読み込み状態を扱う。

## 設計方針

ページはユースケースの入口として扱います。再利用可能な UI はコンポーネントに分離します。API の入出力型や複数領域で使うスキーマは shared contracts に寄せます。

## AI Agent へのルール

画面や UI を変更する場合は、対象ページ、主要状態、エラー状態、受け入れ条件を delivery のタスクで確認します。見た目だけでなく、空状態と失敗時の扱いを確認してから実装します。
