# Server API

Server API は、Web App から利用されるアプリケーション境界です。入力検証、認可境界、エラー形式、外部連携の入口を担当します。

## 責務

- リクエスト入力を検証する。
- API の成功レスポンスとエラーレスポンスを安定させる。
- 外部サービスや永続化層との接続を隠蔽する。
- Web App が扱いやすい粒度のデータを返す。

## 契約

API の入出力は shared contracts と整合させます。クライアントの表示都合だけで、意味の曖昧なフィールドを増やしません。

## AI Agent へのルール

API を追加または変更する場合は、入力、出力、エラー、検証方法を delivery のタスクで確認します。複数箇所で使う型が必要になった場合は、shared contracts への配置を検討します。
