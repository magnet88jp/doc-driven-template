# Shared Contracts

Shared Contracts は、複数領域で共有するデータの意味を安定させるための設計要素です。

## 対象

- API の入出力型。
- DTO とドメイン非依存のデータ構造。
- エラーコードとエラー形式。
- バリデーションスキーマ。
- 複数アプリで使う共通ユーティリティ。

## 対象外

Web 固有の表示ラベル、コンポーネント props、ページ状態、スタイル都合の型は shared contracts に置きません。

## 変更方針

共有契約を変更する場合は、利用側の影響範囲を確認します。破壊的変更は delivery のタスクで明示し、受け入れ条件に移行確認を含めます。

## AI Agent へのルール

似た型を複数箇所に作る前に、shared contracts として定義すべきか確認します。ただし、単一画面だけの一時的な UI 型はアプリ内に留めます。
