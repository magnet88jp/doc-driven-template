# Responsibility Boundary

責務境界は、実装をどこに置くかを判断するための基準です。

## apps/web

`apps/web` は Nuxt アプリケーションです。ページ、レイアウト、コンポーネント、サーバー API、Web 固有の状態管理を担当します。

Web に閉じる表示ロジックは `apps/web` に置きます。複数アプリで共有する型やスキーマは置きません。

## apps/batch

`apps/batch` は将来追加される非同期処理領域です。定期実行、データ同期、通知、集計など、ユーザーリクエストと独立して動く処理を担当します。

## packages/shared

`packages/shared` は共有契約を担当します。DTO、スキーマ、エラー型、共通ユーティリティなど、複数領域で意味を共有するものを置きます。

## infra

`infra` は環境と運用基盤を担当します。デプロイ定義、権限、ネットワーク、ジョブ、監視などを扱います。

## docs

`docs` は合意を担当します。実装の代替ではなく、実装前後の判断材料です。

## 境界を越える場合

境界を越える変更は、delivery に影響範囲と検証方法を書きます。恒久的な責務変更であれば design も更新します。
