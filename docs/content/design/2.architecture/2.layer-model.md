# Layer Model

レイヤーモデルは、依存方向と変更範囲を安定させるための基準です。

## Layers

1. Presentation: ページ、コンポーネント、画面状態、ユーザー操作。
2. Application API: ルーティング、リクエスト検証、認可、ユースケース呼び出し。
3. Domain and Contracts: 型、スキーマ、業務上の不変条件、エラー形式。
4. Integration: 外部 API、データベース、ストレージ、メール、通知。
5. Operations and Infra: デプロイ、環境変数、監視、ジョブ、権限。

## 依存ルール

上位レイヤーは下位レイヤーの契約に依存できます。下位レイヤーは上位レイヤーの UI や画面都合に依存しません。共有契約は UI 表現ではなく、データと振る舞いの意味を表します。

## 変更時の確認

AI Agent は、変更するファイルがどのレイヤーに属するかを確認します。レイヤーをまたぐ変更では、共有契約と docs の更新が必要かを確認します。
