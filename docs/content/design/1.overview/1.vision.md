# Vision

このリポジトリは、AI Agent と人間が docs を介して合意しながら開発する Document Driven Monorepo として運用します。

目的は、実装速度を上げることだけではありません。実装前に意図、責務境界、現在スコープ、受け入れ条件を明示し、AI Agent が暗黙の期待を補完しすぎない状態を作ります。

## 目指す状態

- 実装判断の根拠が docs に残っている。
- 理想設計と現在スコープが分離されている。
- タスクごとに完了条件と検証方法が明確である。
- テーマやドメインが変わっても、同じ開発フローを保てる。
- 将来 `apps/batch`、`infra`、`packages/shared` を追加しても責務境界が崩れない。

## 判断基準

実装前に不明点がある場合、AI Agent はコードを推測で増やす前に docs を確認します。docs にない仕様は、既存の設計原則から導ける最小限に留め、必要なら delivery に差分として記録します。

## 成功条件

人間は docs を読めば、現在何を作っていて、何を作らないのかを判断できます。AI Agent は docs を読めば、実装対象、変更してよい範囲、検証方法を判断できます。
